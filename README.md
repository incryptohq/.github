# incryptohq/.github

Public profile and organization-wide defaults for **iNCRYPTO**.

| Path | Purpose |
|---|---|
| `profile/README.md` | Rendered on the [organization page](https://github.com/incryptohq) |
| `SECURITY.md` | Vulnerability disclosure policy, inherited by every repository in the organization |
| `SUPPORT.md` | Where to get help |
| `CONTRIBUTING.md` | How external contributions are handled |
| `CODE_OF_CONDUCT.md` | Community standards (Contributor Covenant 2.1) |
| `ISSUE_TEMPLATE/` | Default issue configuration for repositories without their own |
| `PULL_REQUEST_TEMPLATE.md` | Default pull request template |

Community health files placed here apply to any repository in the organization that does not define its own. See GitHub's documentation on [default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
