# Support

Repositories in the `incryptohq` organization are not a support channel for the iNCRYPTO platform. Please use the channels below so your request reaches the right team.

| Topic | Channel |
|---|---|
| Account, transactions, product questions | [support@incrypto.me](mailto:support@incrypto.me) or the in-app chat at [incrypto.me](https://incrypto.me) |
| Business, partnerships, integrations, press | [hello@incrypto.me](mailto:hello@incrypto.me) |
| Security vulnerabilities | [security@incrypto.me](mailto:security@incrypto.me) — see [SECURITY.md](SECURITY.md). Never report these publicly. |
| Bugs or questions about code published in a public repository here | Open an issue in that repository |

Please do not share account details, transaction hashes tied to your identity, or any credentials in public issues.
