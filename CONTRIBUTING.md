# Contributing

Thank you for your interest in iNCRYPTO.

## The core platform

The iNCRYPTO platform is proprietary and developed privately. We do not accept external contributions to it, and we do not publish its source code.

## Public repositories

Tooling, integration examples and documentation that we publish in this organization welcome contributions. Before you start:

1. **Open an issue first** for anything larger than a typo or a one-line fix, so we can agree on scope before you invest time.
2. **Keep pull requests focused.** One change per PR, with a clear description of what it does and why.
3. **Follow the conventions of the repository** you are contributing to: code style, tests, commit message format.
4. **Never include secrets, credentials, internal hostnames or customer data** in code, tests, fixtures or commit history.
5. By submitting a contribution you agree that it is licensed under the license of the repository you are contributing to.

## Security

Security issues are handled separately and privately. See [SECURITY.md](SECURITY.md).

## Code of conduct

All interactions in this organization are governed by our [Code of Conduct](CODE_OF_CONDUCT.md).
